# Pipeline index

One folder per upstream analysis. Names give the cohort or scope first, then the analysis.
The internal lab code of each pipeline is kept as `Internal ID` in its README and in the second column here.
"Used by" lists the units (figures, tables, text_statistics) whose `UPSTREAM.json` names the pipeline.
"Section" gives the Methods section and the Supplementary Methods (SM) subsection that describe it.
